# ParliamentX video files

This repository only stores video files for https://parliamentx.com, which is an unofficial summary site. The videos play on the site's own pages. Each file keeps its path from the site: `labour/2569/media/v25.mp4` is served at `https://parliamentx.com/<this repo>/labour/2569/media/v25.mp4`.

Files are added automatically when the site is updated. Do not edit or rename them by hand.
